# Connect Payment Providers

Analytika supports direct API key integrations with major payment providers. Once connected, revenue is automatically pulled and attributed to the exact traffic sources that drove each conversion. No webhooks or code changes required.

## Supported Providers

- **Stripe** — Secret key or restricted key with read access.
- **Polar** — Organization Access Token.
- **Dodo Payments** — Live or test API key.
- **Paddle** — API Secret Key (live or sandbox).
- **Lemon Squeezy** — API token + optional Store ID.

## How to Connect

1. Open your Analytika dashboard and go to **Settings > Revenue Attribution**.
2. Select your payment provider.
3. Paste your API key (and Store ID if using LemonSqueezy).
4. Click **Connect**. Analytika verifies your credentials live against the provider's API.

Once connected, revenue data will automatically appear in your dashboard attributed to the traffic source that drove each sale.

## Manual Revenue Tracking

If you prefer to track revenue from your own code (e.g. on a checkout success page), use the `value` and `currency` keys — these are the reserved field names the tracker maps to typed revenue columns in ClickHouse.

```javascript
// Browser global (after script is loaded)
window.analytika('purchase', {
  value: 49,
  currency: 'USD',
})
```

```typescript
// NPM SDK
import { trackEvent } from '@analytika-me/tracker'

trackEvent('purchase', {
  value: 49,
  currency: 'USD',
})
```

The event name can be any `snake_case` string (`purchase`, `subscription_started`, `upgrade`, etc.). `value` is the numeric revenue amount and `currency` is the ISO currency code.

> Do **not** use `event_value` or `event_currency` — those are internal field names used by the ingestion pipeline, not the keys you pass from your code.
