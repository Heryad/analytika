# Use Tracking Parameters

Get better analytics by tagging your inbound links with UTM parameters or simple referral tags.

## Standard UTM Parameters

Analytika automatically captures standard UTM parameters from the page URL. No configuration required.

| Parameter | Example value |
|---|---|
| `utm_source` | `twitter`, `newsletter` |
| `utm_medium` | `social`, `email`, `cpc` |
| `utm_campaign` | `summer_sale_2026` |
| `utm_term` | `analytics+software` |
| `utm_content` | `header_link` |

### Example

When a visitor lands on:

```
https://yoursite.com/?utm_source=twitter&utm_medium=social&utm_campaign=launch
```

Analytika records the visit under the `launch` campaign from the `twitter` source automatically.

## Ref / Source Parameters (Lightweight Referrals)

If you don't want to use verbose UTM tags, you can use a simple `ref`, `source`, `referrer`, or `via` query parameter instead:

```
https://yoursite.com/?ref=producthunt
https://yoursite.com/?source=indiehackers
https://yoursite.com/?via=newsletter
```

The ingestion pipeline checks for these parameters when the HTTP `Referer` header is absent (e.g. direct links from emails or native apps). The value is used as the referrer source and classified into the appropriate traffic channel (Social, Referral, etc.).

> `ref`, `source`, `referrer`, and `via` are all equivalent. Use whichever fits your workflow.
