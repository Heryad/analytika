# Track Custom Goals

Goals (custom events) let you track specific user actions — clicking a sign-up button, submitting a form, completing a purchase, and so on.

## Important: Event Name Format

Event names are stored in ClickHouse **exactly as you pass them**. There is no normalisation. `"signup_completed"` and `"Signup Completed"` are two completely different events in your dashboard.

**Use `snake_case` consistently across your codebase.**

## 1. Define a Goal

In your Analytika dashboard, navigate to **Settings > Goals** and click **Create Goal**. Enter the exact event name you will fire from your code (e.g. `signup_completed`).

## 2. Trigger the Goal

Use `window.analytika()` to fire the event when the user performs the action.

```javascript
// Simple event — no properties
document.getElementById('signup-btn').addEventListener('click', function () {
  window.analytika('signup_completed')
})
```

### Passing Custom Properties

Pass a flat object of string properties to attach metadata to the event. All values are stored as strings.

```javascript
window.analytika('signup_completed', {
  plan: 'growth',
  billing: 'annual',
})
```

You can later filter your dashboard by these property values.

### Revenue Events

To record a revenue value alongside an event, use the reserved `value` (number) and `currency` (string) keys. These are stored as typed numeric fields in ClickHouse and power the MRR attribution dashboard.

```javascript
window.analytika('purchase', {
  value: 49,        // Must be named `value` — numeric revenue amount
  currency: 'USD',  // Must be named `currency` — ISO currency code
  plan: 'solo',     // Any additional string props
})
```

> Using any other key name (e.g. `price`, `amount`) will store the value as a plain string, not as a revenue figure.

## 3. Declarative HTML Tracking (No JavaScript Required)

You can track clicks on any element without writing JavaScript by adding `data-analytika-event` attributes directly in your HTML.

```html
<button
  data-analytika-event="cta_clicked"
  data-analytika-prop-location="hero"
  data-analytika-value="0"
>
  Get Started
</button>
```

Supported attributes:
- `data-analytika-event` — the event name (required)
- `data-analytika-prop-{key}` — any string property
- `data-analytika-value` — numeric revenue value
- `data-analytika-currency` — ISO currency code

Short aliases (`data-ana-event`, `data-prop-{key}`, `data-value`, `data-currency`) also work.
