# Track Conversion Funnels

Funnels allow you to measure the drop-off rate between different steps in a user journey. For example: `Landing Page -> Pricing Page -> Checkout -> Success`.

## Creating a Funnel

1. Go to your Analytika dashboard and click **Funnels**.
2. Click **Create Funnel**.
3. Define the steps in your funnel. Steps can be **Pageviews** (e.g., visited `/pricing`) or **Custom Goals** (e.g., triggered `Checkout Completed`).

## Analyzing the Funnel

Once created, the funnel will visually display the conversion rate between each step. You can use the global dashboard filters to see how different segments perform.

For example, filter the dashboard by `utm_source = twitter` to see the exact conversion funnel for users coming from Twitter compared to organic traffic!
