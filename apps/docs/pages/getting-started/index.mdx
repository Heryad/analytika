# Get started in 4 steps

Get up and running with Analytika by following these 4 simple steps.

## 1. Create a Website

Go to your Analytika Dashboard and click **Add Website**. Enter your domain name and click **Create**.

## 2. Copy the Tracking Script

After creation, you will receive a tracking script that looks like this:

```html
<script defer src="https://analytika.me/a.js" data-website-id="YOUR-WEBSITE-ID"></script>
```

## 3. Install on your Site

Paste this snippet into the `<head>` of your website. If you're using a framework or CMS, refer to the **Installation Guides** in the sidebar:

- [Next.js](/install/nextjs)
- [NPM SDK](/install/npm)
- [WordPress](/install/wordpress)
- [Webflow](/install/webflow)

## 4. Verify Tracking

Visit your website in an incognito window. You should instantly see a new active visitor appear on your Analytika dashboard in real-time.
