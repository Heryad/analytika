# Model Context Protocol (MCP)

Analytika is a remote **Model Context Protocol** server. Claude, ChatGPT, Cursor, and other MCP clients can read your live analytics after you sign in with OAuth.

You do **not** paste a bearer token into Claude or ChatGPT. Those apps open Analytika, you click **Allow access**, and they receive a short-lived OAuth token automatically.

## MCP server URL

```
https://api.analytika.me/mcp
```

## Claude

1. Open **Settings → Connectors → Add custom connector**.
2. Name: `Analytika`
3. URL: `https://api.analytika.me/mcp`
4. Leave authentication empty.
5. Connect. Claude opens Analytika — sign in if needed, then click **Allow access**.

## ChatGPT

1. Enable **Developer Mode** under **Settings → Connectors**.
2. Create a connector with URL `https://api.analytika.me/mcp`.
3. Choose **OAuth** (not an API key).
4. Sign in to Analytika and allow access.

## Cursor / Claude Desktop

Add this to `.cursor/mcp.json` or `claude_desktop_config.json`. Cursor will run the same OAuth browser flow:

```json
{
  "mcpServers": {
    "analytika": {
      "url": "https://api.analytika.me/mcp"
    }
  }
}
```

Local or scripted clients can still send `Authorization: Bearer ana_mcp_live_...` using the personal token from **Dashboard → Settings → MCP**.

Once connected, ask:

*"How many people are on my website right now?"*  
or  
*"Create a markdown table of my top 10 referrers this week."*
