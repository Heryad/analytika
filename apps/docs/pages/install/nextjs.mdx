# Next.js Integration

Adding Analytika to your Next.js application is simple. We officially support both the **App Router** and **Pages Router**.

## App Router (`app/`)

Inject the script in your `app/layout.tsx` using Next.js's `Script` component.

```tsx
import Script from 'next/script'

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <head>
        <Script
          defer
          src="https://analytika.me/a.js"
          data-website-id="YOUR-WEBSITE-ID"
          strategy="afterInteractive"
        />
      </head>
      <body>
        {children}
      </body>
    </html>
  )
}
```

## Pages Router (`pages/`)

Add the script to your `pages/_document.tsx`.

```tsx
import { Html, Head, Main, NextScript } from 'next/document'

export default function Document() {
  return (
    <Html lang="en">
      <Head>
        <script defer src="https://analytika.me/a.js" data-website-id="YOUR-WEBSITE-ID"></script>
      </Head>
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  )
}
```

## Tracking Custom Events

Once the script is loaded, use `window.analytika()` to track custom events anywhere in your app.

Event names must be consistent and use `snake_case` — `"signup_completed"` and `"Signup Completed"` are stored as two separate events.

```tsx
// Simple event
window.analytika('signup_completed')

// Event with custom properties
window.analytika('plan_selected', {
  plan: 'growth',
  billing: 'annual',
})

// Revenue event (use `value` and `currency` for MRR attribution)
window.analytika('purchase', {
  value: 49,
  currency: 'USD',
  plan: 'solo',
})
```
