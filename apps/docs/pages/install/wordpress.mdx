# WordPress Integration

Integrating Analytika into WordPress takes less than two minutes. No heavy plugins required.

## Method 1: Using a Header/Footer Plugin (Recommended)

1. Log into your WordPress Admin Dashboard.
2. Go to **Plugins > Add New** and search for **WPCode** or **Insert Headers and Footers**.
3. Install and activate the plugin.
4. Go to **Code Snippets > Header & Footer**.
5. Paste your Analytika tracking script into the **Header** section:
   ```html
   <script defer src="https://analytika.me/a.js" data-website-id="YOUR-WEBSITE-ID"></script>
   ```
6. Click **Save Changes**.

## Method 2: Editing `functions.php`

If you prefer not to use a plugin, you can inject the script directly into your theme's `functions.php`.

```php
function add_analytika_script() {
    echo '<script defer src="https://analytika.me/a.js" data-website-id="YOUR-WEBSITE-ID"></script>';
}
add_action('wp_head', 'add_analytika_script');
```

## Tracking Custom Events

To track a specific action (e.g. a form submission), add an inline script that calls `window.analytika()` after the event fires.

```html
<script>
  document.addEventListener('DOMContentLoaded', function () {
    var form = document.getElementById('contact-form')
    if (form) {
      form.addEventListener('submit', function () {
        window.analytika('form_submitted', { form: 'contact' })
      })
    }
  })
</script>
```

Event names are stored exactly as passed — use `snake_case` to keep your dashboard clean.
