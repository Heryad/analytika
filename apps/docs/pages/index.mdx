# Analytika Docs

Welcome to the official documentation for **Analytika**. 

Analytika is a high-speed, privacy-first web analytics platform designed with a native AI integration via the Model Context Protocol (MCP).

## Why Analytika?

- **Zero Cookies**: 100% GDPR, CCPA, and PECR compliant out of the box. No cookie banners required.
- **High-Speed Telemetry**: Ultra-fast edge telemetry collection for minimal overhead on your users.
- **AI-Native (MCP)**: Native integration with AI assistants (like Claude, Cursor, and ChatGPT) using the Remote MCP protocol, allowing AI to read and monitor your live analytics data.
